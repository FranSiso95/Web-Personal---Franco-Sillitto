# 🌐 Web Personal - Franco Sillitto

Este es mi portfolio personal desarrollado con React, donde muestro mis proyectos, habilidades y formas de contacto.

---

## 🚀 Tecnologías utilizadas

- React
- JavaScript
- HTML5
- CSS3

## 📌 Proyectos destacados

### 🧩 Librería Rick & Morty
Web que consume la API de Rick & Morty para mostrar personajes con búsqueda y paginación.

### ⚙️ Proyecto JavaScript
Aplicación desarrollada con JavaScript puro enfocada en lógica y manipulación del DOM.

### ⚛️ Proyecto React
Aplicación desarrollada con React utilizando componentes reutilizables y manejo de estado.
